# Site do ENCOMP 2025

Site oficial do **ENCOMP 2025 (Encontro de Computação)**, evento do IFSULDEMINAS - Campus Passos realizado de 3 a 7 de novembro de 2025, com palestras, minicursos e campeonatos.

**No ar:** https://site-encomp.vercel.app

Desenvolvi o site sozinho e também fiz parte da equipe de planejamento do evento. As inscrições ficaram abertas por cerca de 6 semanas e o site recebeu **736 inscrições em 25 palestras e minicursos**, de aproximadamente 340 participantes.

## O que tem no site

- Apresentação do evento, programação dos 5 dias e lista de palestrantes
- Minicursos, com as gravações dos minicursos online disponibilizadas depois do evento
- **Formulário de inscrição próprio**, com a identidade visual do evento, que envia as respostas direto para uma planilha do Google Forms
- Galeria de fotos, patrocinadores e perguntas frequentes
- Botão flutuante de inscrição, sempre visível durante a navegação

## Tecnologias

React · TypeScript · Vite · Tailwind CSS · shadcn/ui · Lucide Icons · Google Forms · deploy na Vercel

## Como rodar localmente

```bash
git clone https://github.com/LucasTerrau/Site-Encomp.git
cd Site-Encomp
npm install
npm run dev
```

O site abre em http://localhost:5173.
